# Claim registry — DIALOGUE (the window a mission's script speaks through, and its lifecycle)

Level 2 ledger. Index: [registry.md](registry.md) · spec: [`formats/dialogue/format.md`](../formats/dialogue/format.md). Legend: `✔ promoted` (also in the spec) · `● active` · `✖ retracted`. IDs are permanent.

This ledger is the **presentation** side of `claims/mission.md` and `claims/trigger.md`. Those
say what the script decides and which resource its decision names; these say what object
draws it, everything that can enter that path, what happens when the resource is absent,
what ends the display and what the window measures. The glyph rule — how a text byte becomes
a pixel, and the font atlases — is **not** here; that is EXP-0097's area and this ledger
cites it rather than restating it. Ids here are written **plain** in the first cell.

Every measurement names the root it was read from. `rom.exe` is **byte-identical in both
roots** (`sha256 942e9b72…d367d03`, 1 977 344 B), so every address below is a fact about
both and only resources can differ by language.
