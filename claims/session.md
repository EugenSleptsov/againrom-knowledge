# Claim registry — SESSION (the game's own lifecycle: object, phase, clock, map load, mission end)

Level 2 ledger. Index: [registry.md](registry.md) · spec: [`formats/session/format.md`](../formats/session/format.md). Legend: `✔ promoted` (also in the spec) · `● active` · `✖ retracted`. IDs are permanent.

This ledger covers the machine the owner named as
`newgame → chargen → loadmap → playing → finish mission` and `city → pick mission → go`: which
object holds a session, what phase it is in, **what advances the simulation's counters and how
fast**, how a map becomes a session, and what happens when a mission ends. It is not a file
format. The map's own bytes are `claims/alm.md`; the actors it spawns are `claims/unit.md` and
`claims/hero.md`; the shop the town screen opens is `claims/shop.md`.

`SESS-CLOCK-005` says how fast the sub-tick runs; `SESS-PACE-018`
([EXP-0093](../experiments/EXP-0093-move-rate/)) says **which loop issues it**, that the same
iteration issues the `0x401` presentation tick `ANIM-CLOCK-001` names, and which two of the idle
handler's four arms let the two diverge.
