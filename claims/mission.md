# Claim registry — MISSION (what it takes to start a campaign mission and end it in a win)

Level 2 ledger. Index: [registry.md](registry.md) · spec: [`formats/mission/format.md`](../formats/mission/format.md). Legend: `✔ promoted` (also in the spec) · `● active` · `✖ retracted`. IDs are permanent.

This ledger is the **third** side of the mission triangle. `claims/alm.md` says what a map
*stores*; `claims/trigger.md` says what the evaluator *does* with the script once it is
compiled. These rows say what a campaign mission *is* end to end: where the player's units
come from, what puts them on a cell, which shipped file each placed person is read out of,
what carries the dialogue, and which of the engine's parts a consumer must build before a
mission can start and finish. Ids here are written **plain** in the first cell.
